# AgentLoom v0.1.0-rc.1

This release candidate freezes the initial-round code and documentation for a
recorded competition rehearsal. It is not the final `v0.1.0` release.

## Completed capabilities

- AgentTeams/HiClaw `v1.1.2` is the primary collaboration runtime for a Manager
  and three distinct business roles: Investigator, Implementer, and Verifier.
- `CoordinationTrace` binds Manager delegation and role-owned handoffs to the
  evidence chain.
- Skill Registry contracts, three-layer detection, signed one-time grants,
  Policy Broker MCP routing, Human approval, and append-only evidence fail
  closed at trust boundaries.
- Deterministic offline cases exercise repair, independent hidden tests,
  failure, bounded retry, and rollback without model quota.
- Verified local evidence records an unattended Qwen repair, a StepFun
  four-role rollback, and a Human-owned L2 approval.
- `-PublicOutput` redacts local filesystem paths during competition replay.

## Reproduce from a fresh clone

The portable, no-cloud path runs the deterministic local workflow:

```powershell
git clone https://github.com/WilliamClifton-dev/AgentLoom.git
Set-Location AgentLoom
git checkout v0.1.0-rc.1
.\scripts\bootstrap.ps1 -Profile lite
.\scripts\demo.ps1
```

Run the local TUI with:

```powershell
.venv\Scripts\agentloom tui
```

## Replay verified AgentTeams evidence

This path requires the documented AgentTeams deployment and ignored local
evidence from a previously verified live run. It does not call a model:

```powershell
.\scripts\competition-rollback-demo.ps1 `
  -Mode replay `
  -NoTui `
  -PublicOutput

.\scripts\competition-rollback-demo.ps1 -Mode replay -PublicOutput
```

Expected public summary fields include AgentTeams `v1.1.2`, status `PASS`,
model `step-3.7-flash`, `roleEventCount` `4`, and
`artifactsDirectory` `<redacted>`.

  repository.
- Full bootstrap has not been validated on additional clean Windows machines.
- AgentTeams upstream PR
  [#1141](https://github.com/agentscope-ai/AgentTeams/pull/1141) remains open.

## Rollback

Use the previous commit on `main` for a source rollback. Local demo artifacts are
ignored and can be regenerated. AgentTeams deployment rollback uses the pinned
`v1.1.2` references and the procedures in
[`windows-agentteams.md`](../deployment/windows-agentteams.md).
